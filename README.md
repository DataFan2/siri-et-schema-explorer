# SIRI ET Schema Explorer

Interaktiver Explorer für das SIRI ET (Estimated Timetable) Schema – durchsuchbarer Elementbaum mit Kardinalitäten und Beschreibungen.

Live: https://datafan2.github.io/siri-et-schema-explorer/

## Lizenz

Der Code dieses Repositories (HTML, CSS, JavaScript) steht unter der [MIT-Lizenz](LICENSE).

Die Schema-Inhalte (Elementnamen, Kardinalitäten, Beschreibungstexte in `data.json`) basieren auf dem offiziellen CEN SIRI-Standard (v2.2) und unterliegen **nicht** dieser Lizenz, sondern dem Copyright von CEN. Quelle: [github.com/SIRI-CEN/SIRI](https://github.com/SIRI-CEN/SIRI)
